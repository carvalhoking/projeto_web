# 🚀 Início Rápido - Controlador de Rotina

## Para começar AGORA:

### 1️⃣ Entre na pasta do projeto:
```bash
cd /workspace/controlador-rotina
```

### 2️⃣ Inicie o aplicativo:
```bash
npm start
```

### 3️⃣ Escolha como executar:

#### 📱 **No seu celular (MELHOR OPÇÃO):**
- Instale o app "Expo Go" na loja do seu celular
- Escaneie o QR Code que apareceu no terminal
- Pronto! O app abrirá no seu celular

#### 🌐 **No navegador:**
- Pressione `w` no terminal
- Ou acesse: http://localhost:8081

#### 🤖 **No emulador Android:**
```bash
npm run android
```

#### 🍎 **No simulador iOS (somente Mac):**
```bash
npm run ios
```

## 💡 Dicas:

1. **Primeira vez?** Use `npm start` e escolha a opção web (pressione `w`)
2. **Quer testar no celular?** Instale o Expo Go e escaneie o QR Code
3. **Mudou o código?** O app recarrega automaticamente (hot reload)
4. **Problemas?** Pressione `r` no terminal para recarregar o app
