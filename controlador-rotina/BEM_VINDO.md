## 🚀 COMECE AGORA EM 3 PASSOS

### 1️⃣ Entre na pasta do projeto
```bash
cd /workspace/controlador-rotina
```

### 2️⃣ Inicie o servidor
```bash
npm start
```

### 3️⃣ Escolha como executar

#### Opção A: No Navegador (mais rápido)
- Pressione `w` no terminal
- Ou acesse: http://localhost:8081

#### Opção B: No Celular (melhor experiência)
- Instale o app "Expo Go" no seu celular
- Escaneie o QR Code que apareceu no terminal

## 📱 COMO USAR O APP

### Login:
1. Digite qualquer e-mail válido (ex: teste@email.com)
2. Digite senha com 6+ caracteres (ex: 123456)
3. Clique em "Entrar"

### Adicionar Rotina:
1. Clique no botão **+** (roxo, no canto inferior)
2. Preencha título, descrição, categoria e período
3. Clique em "Salvar"

### Gerenciar Rotinas:
- ✅ Marcar concluída: Clique no checkbox
- 🗑️ Excluir: Clique no ícone de lixeira
- 📊 Ver estatísticas: No topo da tela
